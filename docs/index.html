Unidad 1 · Universo de Información

Objetivo

Construir un inventario del trabajo y los recursos existentes para comprender el punto de partida. Antes de diseñar un portafolio es necesario reconocer qué información ya existe, dónde se encuentra y cuál es su estado.

Temas

  • Inventario de contenido: Identificar proyectos, imágenes, textos, bocetos, publicaciones, archivos y cualquier otro material disponible.
  • Universo de información: Visualizar el conjunto completo de recursos sin realizar aún una selección.
  • Estado del contenido: Reconocer qué información está completa, incompleta, duplicada o dispersa.
  • Organización inicial: Agrupar materiales de forma preliminar mediante carpetas, listas o colecciones.
  • Vacíos y oportunidades: Detectar qué información hace falta producir, recuperar o documentar.

Unidad 2 · Identidad

Objetivo

Descubrir y reafirmar la identidad profesional a partir del análisis del propio trabajo. La identidad no se define únicamente por un nombre o un logotipo, sino por los patrones, intereses y decisiones que permanecen a lo largo del tiempo.

Temas

  • Reconocimiento de patrones: Identificar elementos, temas, técnicas y procesos que aparecen de forma recurrente.
  • Intereses y motivaciones: Comprender qué impulsa la práctica profesional y qué tipo de proyectos generan mayor satisfacción.
  • Curaduría: Diferenciar el trabajo que representa la práctica actual del que ya no refleja los intereses personales.
  • Síntesis conceptual: Construir una descripción clara y coherente de la práctica profesional.
  • Posicionamiento: Definir cómo se desea ser percibido y qué tipo de oportunidades se buscan atraer.

Unidad 3 · Arquitectura de Información

Objetivo

Transformar un conjunto de contenidos en un sistema organizado, comprensible y escalable mediante principios de estructura, jerarquía y organización de información.

Temas

  • Agrupación: Reunir contenidos con características o propósitos similares.
  • Categorización: Definir categorías que faciliten la comprensión del contenido.
  • Jerarquía: Establecer prioridades y niveles de importancia entre la información.
  • Relaciones: Identificar conexiones entre proyectos, categorías y contenidos.
  • Estructura de navegación: Diseñar una organización que permita recorrer la información de manera clara.

Unidad 4 · Lenguajes de Representación

Objetivo

Comprender cómo la información puede representarse mediante lenguajes de marcado antes de abordar el desarrollo web. El énfasis está en estructurar ideas, no en programar.

Temas

  • Texto plano: Comprender el texto como la representación más simple y universal de la información.
  • Lenguajes de marcado: Introducción al concepto de marcado y estructura documental.
  • Markdown: Utilizar Markdown para organizar información mediante encabezados, listas, enlaces e imágenes.
  • Documentación: Escribir documentación clara y útil para describir proyectos y procesos.
  • Especificación: Aprender a comunicar ideas y estructuras de manera precisa mediante texto.

Unidad 5 · Sistema Visual

Objetivo

Traducir la identidad y la estructura de información en un sistema visual consistente que sirva como base para el desarrollo del portafolio.

Temas

  • Concepto visual: Relacionar identidad y lenguaje gráfico.
  • Tipografía: Seleccionar y utilizar sistemas tipográficos de manera coherente.
  • Color: Construir una paleta funcional basada en criterios de comunicación.
  • Composición: Organizar los elementos visuales mediante principios de jerarquía y ritmo.
  • Consistencia: Definir reglas visuales que permitan mantener coherencia en todo el proyecto.

Unidad 6 · Entorno de Desarrollo

Objetivo

Preparar un entorno de trabajo profesional que permita construir, documentar y mantener el proyecto durante su desarrollo.

Temas

  • GitHub: Crear y organizar repositorios para el proyecto.
  • Git: Comprender el control de versiones como herramienta de trabajo.
  • Visual Studio Code: Configurar el editor y conocer sus herramientas principales.
  • Estructura del proyecto: Organizar carpetas y archivos siguiendo buenas prácticas.
  • Flujo de trabajo: Establecer una metodología de desarrollo y documentación.

Unidad 7 · HTML

Objetivo

Construir la estructura semántica del portafolio a partir de la arquitectura de información previamente definida.

Temas

  • Documento HTML: Comprender la estructura básica de un documento web.
  • HTML semántico: Utilizar etiquetas con significado para organizar el contenido.
  • Componentes: Construir bloques reutilizables para representar la información.
  • Accesibilidad: Incorporar principios básicos de accesibilidad desde la estructura.
  • Contenido estructurado: Traducir la arquitectura de información a HTML.

Unidad 8 · CSS

Objetivo

Desarrollar un sistema de presentación visual consistente utilizando CSS como herramienta para materializar el sistema visual.

Temas

  • Modelo de caja: Comprender la distribución espacial de los elementos.
  • Layout: Construir estructuras flexibles mediante Flexbox y Grid.
  • Sistema visual: Implementar tipografía, color, espaciado y componentes.
  • Diseño responsive: Adaptar la interfaz a distintos dispositivos.
  • Componentización: Mantener consistencia mediante estilos reutilizables.

Unidad 9 · JavaScript

Objetivo

Incorporar comportamiento e interacción para enriquecer la experiencia de uso del portafolio sin perder claridad ni simplicidad.

Temas

  • Fundamentos del lenguaje: Comprender variables, funciones y estructuras básicas.
  • Manipulación del documento: Modificar el contenido y comportamiento mediante JavaScript.
  • Interacciones: Diseñar acciones significativas para el usuario.
  • Estados: Gestionar cambios de interfaz según la interacción.
  • Experiencia: Integrar comportamiento como parte del concepto del sitio.

Unidad 10 · Publicación

Objetivo

Publicar el portafolio y comprender el proceso necesario para mantenerlo, actualizarlo y hacerlo evolucionar con el tiempo.

Temas

  • Control de versiones: Preparar el proyecto para su publicación.
  • Despliegue: Publicar el sitio utilizando plataformas de hosting.
  • Dominio: Configurar un dominio propio cuando sea necesario.
  • Optimización: Mejorar rendimiento, accesibilidad y buenas prácticas.
  • Evolución: Mantener y actualizar el portafolio como un proyecto vivo.
