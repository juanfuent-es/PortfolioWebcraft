# Unidad 4 · Sistema Visual

## Objetivo

Construir un sistema visual coherente a partir de la identidad y la estructura de información definidas previamente. El objetivo no es diseñar páginas aisladas, sino establecer reglas de tipografía, color, composición y recursos gráficos que puedan aplicarse de manera consistente y flexible en todo el portafolio.

## Temas

### Referencias visuales

**Objetivo:** Identificar referentes, características y decisiones visuales que puedan orientar la construcción del sistema.

**Descripción:** Las referencias permiten ampliar el vocabulario visual antes de comenzar a diseñar. Pueden provenir de sitios web, publicaciones, identidades, fotografía, arquitectura, cine, arte, música, objetos, interfaces o cualquier otro contexto relacionado con las características identificadas durante la Unidad 2.

El objetivo no es construir un moodboard basado únicamente en gustos ni copiar soluciones existentes. Las referencias deben analizarse para reconocer **qué características resultan relevantes**: contraste, escala, ritmo, densidad, geometría, organicidad, textura, movimiento, precisión, irregularidad u otras propiedades.

Analizar referencias permite pasar de “me gusta” a preguntas más específicas: **¿qué me interesa de esto?, ¿qué característica expresa?, ¿qué decisión produce esa percepción?**

---

### Tipografía

**Objetivo:** Definir una selección tipográfica capaz de construir identidad, jerarquía y legibilidad.

**Descripción:** La tipografía cumple simultáneamente una función expresiva y una función informativa. Una familia puede aportar características particulares a la identidad, pero también debe permitir organizar y leer correctamente títulos, textos, etiquetas, navegación y otros niveles de información.

El sistema puede distinguir entre una **tipografía display**, con mayor peso expresivo, y una **tipografía de lectura**, destinada a contenidos extensos o funcionales. Estas funciones pueden resolverse con familias diferentes o mediante una misma familia con suficientes pesos, estilos o variables.

La selección debe considerar legibilidad, contraste, disponibilidad para web, licencias, idiomas, pesos y posibilidades de uso. Más adelante estas decisiones se convertirán en reglas tipográficas reutilizables dentro del sitio.

---

### Color

**Objetivo:** Construir una paleta de color coherente con la identidad y suficientemente flexible para funcionar como sistema.

**Descripción:** Una paleta no consiste solamente en seleccionar colores atractivos. Cada color puede asumir una función dentro del sistema: fondo, texto, superficie, acento, interacción, información secundaria o estados específicos.

Los atributos identificados previamente pueden utilizarse como punto de partida para explorar relaciones cromáticas, pero la selección también debe considerar necesidades funcionales como **contraste, legibilidad, consistencia y accesibilidad**.

El sistema debe definir tanto los colores como sus relaciones y condiciones de uso. Una identidad puede utilizar diferentes combinaciones sin perder coherencia si existen reglas que permitan reconocer cuándo y cómo utilizarlas.

---

### Composición

**Objetivo:** Definir principios de organización espacial que permitan estructurar diferentes contenidos de manera consistente.

**Descripción:** La composición establece relaciones entre elementos mediante alineación, proporción, escala, espacio, ritmo y repetición. En lugar de diseñar cada página de manera independiente, un sistema compositivo permite establecer principios capaces de adaptarse a diferentes tipos y cantidades de contenido.

La arquitectura de información construida previamente proporciona la jerarquía; la composición comienza a darle una expresión espacial. La información principal puede ocupar mayor escala o espacio, mientras que contenidos secundarios pueden organizarse mediante relaciones diferentes.

El objetivo todavía no es diseñar todas las páginas del portafolio, sino reconocer **qué reglas espaciales pueden mantenerse cuando cambia el contenido**.

---

### Componentes y reglas

**Objetivo:** Convertir las decisiones visuales en elementos y reglas reutilizables.

**Descripción:** Un sistema visual se vuelve más robusto cuando sus decisiones pueden repetirse sin tener que resolver cada caso desde cero. Tipografías, colores, espacios, imágenes, bordes, etiquetas y otros elementos pueden comenzar a organizarse como partes reutilizables.

Un componente no debe entenderse todavía exclusivamente como un componente de código. En esta etapa puede ser una **unidad visual recurrente**: una tarjeta de proyecto, una etiqueta, un encabezado, un bloque de texto o una forma de presentar imágenes.

Las reglas permiten que estos elementos cambien sin perder coherencia. Un sistema puede admitir diferentes contenidos, tamaños, combinaciones o niveles de expresión si define qué propiedades permanecen constantes y cuáles pueden variar.

# Actividades

Estas actividades parten de la identidad definida y de la arquitectura de información construida previamente. El objetivo será **traducir características y estructuras en decisiones visuales**, evitando comenzar directamente por el diseño de páginas completas.

## Actividad 1 · Atributos y referencias visuales

### Objetivo

Traducir las características identificadas durante la Unidad 2 en un conjunto de referencias visuales que permitan explorar diferentes posibilidades de expresión.

### Instrucciones

Recupera las características principales que identificaste durante la Unidad 2.

Por ejemplo:

```text
experimental
preciso
orgánico
documental
lúdico
tecnológico
artesanal
```

Busca referencias relacionadas con estas características.

No tienen que ser únicamente sitios web. Puedes utilizar:

- Diseño gráfico.
- Tipografía.
- Fotografía.
- Arte.
- Arquitectura.
- Cine.
- Moda.
- Objetos.
- Interfaces.
- Publicaciones.
- Materiales.
- Texturas.
- Movimiento.
- Espacios.
- Elementos naturales.

Para cada referencia identifica **qué característica te interesa y por qué**.

Evita registrar únicamente “me gusta” o “no me gusta”. Intenta reconocer propiedades concretas.

Por ejemplo:

```text
Referencia:
Característica: Orgánico

Me interesa:
- irregularidad;
- repetición;
- formas curvas;
- variaciones de escala;
- crecimiento;
- ausencia de una retícula evidente.
```

### Entregable

Una colección de referencias acompañada por:

1. Característica relacionada.
2. Elementos relevantes de cada referencia.
3. Patrones encontrados entre las referencias.
4. Características visuales que podrían formar parte de tu sistema.

## Actividad 2 · Tipografía y color

### Objetivo

Construir una primera selección tipográfica y cromática a partir de las características identificadas.

### Instrucciones

Selecciona una propuesta tipográfica para tu portafolio.

Define:

- Tipografía principal o display.
- Tipografía para lectura.
- Pesos disponibles.
- Estilos necesarios.
- Fuente o licencia.
- Razón de la selección.

La selección puede utilizar una o varias familias dependiendo de las necesidades del sistema.

Después construye una paleta inicial.

Define:

- Color de fondo.
- Color principal de texto.
- Colores secundarios.
- Color o colores de acento.
- Posibles combinaciones.
- Función de cada color.

Comprueba que las combinaciones destinadas a texto mantengan suficiente contraste y legibilidad.

No diseñes todavía páginas completas. Trabaja con **muestras, relaciones y reglas**.

### Entregable

Un documento visual que incluya:

1. Selección tipográfica.
2. Jerarquías tipográficas iniciales.
3. Paleta de color.
4. Función de cada color.
5. Ejemplos básicos de combinaciones.
6. Justificación breve de las decisiones.

## Actividad 3 · Sistema visual

### Objetivo

Convertir las decisiones anteriores en un conjunto inicial de reglas reutilizables.

### Instrucciones

Utiliza la arquitectura de información definida en la Unidad 3 para probar el sistema con contenido real.

Define reglas para:

- Títulos.
- Subtítulos.
- Texto.
- Etiquetas.
- Enlaces.
- Imágenes.
- Espaciado.
- Alineación.
- Escala.
- Color.
- Fondos.
- Elementos recurrentes.

Identifica cuáles propiedades deben permanecer constantes y cuáles pueden variar.

Por ejemplo:

```text
TÍTULO

Tipografía: Display
Peso: Bold
Escala: Grande
Alineación: Variable
Color: Texto principal

Puede variar:
- tamaño;
- posición;
- relación con imagen.

Debe permanecer:
- familia tipográfica;
- peso;
- relación jerárquica.
```

Prueba las reglas utilizando diferentes proyectos. Un sistema debe ser capaz de recibir contenidos distintos sin necesitar una solución completamente nueva para cada uno.

### Entregable

Una primera especificación del sistema visual que incluya:

1. Tipografías.
2. Escala y jerarquías.
3. Paleta de color.
4. Principios de composición.
5. Espaciado.
6. Tratamiento de imágenes.
7. Elementos recurrentes.
8. Reglas de uso.
9. Variables permitidas.

El resultado no debe entenderse como una identidad terminada. Será una **primera especificación del sistema visual** que podrá probarse, ajustarse y formalizarse durante la construcción del portafolio.
