# Portfolio Webcraft

## Aprende cómo funciona la web y construye un portafolio hecho por ti y para ti.

---

## Descripción

Portfolio Webcraft es una guía práctica para diseñadores, artistas, fotógrafos y creativos que desean comprender cómo funciona la web para diseñar, construir y mantener un portafolio propio.

Este no es un curso de programación ni una colección de plantillas.

Es una introducción al oficio de construir espacios digitales: entender cómo organizar información, diseñar sistemas visuales, tomar decisiones de interfaz y utilizar herramientas contemporáneas para publicar un sitio que realmente represente tu trabajo.

Al finalizar el curso, cada participante tendrá un portafolio web funcional, publicado y preparado para evolucionar con el tiempo.

---

# Objetivos

* Comprender la web como un sistema de comunicación y presentación.
* Organizar y estructurar contenido profesional.
* Diseñar sistemas visuales mínimos para interfaces digitales.
* Construir componentes y layouts reutilizables.
* Utilizar herramientas contemporáneas de desarrollo asistido.
* Publicar y mantener un portafolio propio.
* Desarrollar autonomía digital.

---

# Resultados de aprendizaje

Al finalizar el curso podrás:

* Organizar tu trabajo profesional para presentarlo digitalmente.
* Diseñar una arquitectura de información adecuada para tu disciplina.
* Construir páginas web utilizando HTML y CSS asistidos por IA.
* Crear componentes reutilizables.
* Publicar tu portafolio utilizando GitHub y Vercel.
* Mantener y evolucionar tu sitio de manera independiente.

# Glosario mínimo

## Portafolio

Colección organizada de proyectos que comunica quién eres y qué haces.

## Arquitectura de información

Organización y estructura del contenido.

## Componente

Elemento reutilizable dentro de una interfaz.

## Hero

Sección principal de una página.

## Layout

Estructura espacial de una interfaz.

## Responsive

Capacidad de adaptación a distintos tamaños de pantalla.

## HTML

Lenguaje que define la estructura del contenido.

## CSS

Lenguaje que define la presentación visual.

## Git

Sistema para registrar cambios en un proyecto.

## GitHub

Plataforma para almacenar y colaborar en proyectos.

## Vercel

Servicio para publicar sitios web.

## IA asistida

Uso de herramientas de inteligencia artificial para acelerar procesos sin reemplazar el criterio humano.

# Filosofía Webcraft

* Pensamiento antes que automatización.
* Sistemas antes que soluciones rápidas.
* Comprensión antes que delegación.
* Construcción antes que consumo.
* Autonomía digital antes que dependencia tecnológica.
* IA como asistente, no como reemplazo del pensamiento crítico.
