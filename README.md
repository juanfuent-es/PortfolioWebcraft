# Portfolio WebCraft

_Construye tu propio portafolio mientras aprendes cómo funciona la web._

Aprende a organizar tu contenido, estructurar información y construir un sistema visual para dar vida a tu portafolio y publicarlo en línea.

**No necesitas saber programar.** Aprenderás los fundamentos del diseño y desarrollo web para escribir código asistido por IA.

*Tú defines la dirección creativa; la IA te ayuda a construirla.*

---

## Objetivo

Diseñar, desarrollar y publicar un portafolio web profesional mientras se comprenden los principios con los que la información, el diseño y la tecnología se convierten en un sistema web funcional.

El portafolio es el proyecto articulador del programa: permite trabajar con contenido propio, tomar decisiones de identidad, construir un sistema visual, desarrollar una estructura técnica y publicar un sitio que pueda mantenerse y evolucionar de forma autónoma.

La inteligencia artificial se utiliza como herramienta de apoyo para comprender, especificar, implementar, revisar y depurar. No sustituye la dirección creativa, el criterio ni la comprensión del proceso.

---

## Metodología WebCraft

Portfolio WebCraft se desarrolla mediante una metodología centrada en comprender cómo funciona la web antes de automatizar su construcción.

La metodología prioriza:

- comprensión antes que automatización;
- pensamiento antes que ejecución;
- sistemas antes que páginas;
- organización antes que producción;
- funcionalidad antes que estética;
- estructura de información antes que interfaz;
- criterio antes que herramientas.

La estética apoya la identidad del proyecto. El concepto puede informar posteriormente la interacción y la experiencia, pero las decisiones visuales y técnicas deben sostener siempre la claridad, la función y la capacidad de mantenimiento.

## Unidades

### 1 · Universo de Información

**Objetivo / Propósito:** Construir un inventario del trabajo y los recursos existentes para comprender el punto de partida, reconocer el estado de la información y detectar vacíos antes de diseñar el portafolio.

---

### 2 · Identidad

**Objetivo / Propósito:** Descubrir y reafirmar la identidad profesional mediante el análisis de patrones, intereses, motivaciones y decisiones presentes en el propio trabajo.

---

### 3 · Arquitectura de Información

**Objetivo / Propósito:** Transformar el contenido disponible en un sistema organizado, comprensible y escalable mediante agrupación, categorización, jerarquía, relaciones y navegación.

---

### 4 · Lenguajes de Representación

**Objetivo / Propósito:** Comprender cómo representar y estructurar información mediante texto plano, lenguajes de marcado y Markdown antes de abordar el desarrollo web.

---

### 5 · Sistema Visual

**Objetivo / Propósito:** Traducir la identidad y la arquitectura de información en un sistema visual consistente basado en reglas de tipografía, color, composición y coherencia.

---

### 6 · Entorno de Desarrollo

**Objetivo / Propósito:** Preparar un entorno profesional para construir, documentar y mantener el proyecto mediante GitHub, Git, Visual Studio Code y una estructura de archivos organizada.

---

### 7 · HTML

**Objetivo / Propósito:** Construir la estructura semántica y accesible del portafolio a partir de la arquitectura de información previamente definida.

---

### 8 · CSS

**Objetivo / Propósito:** Materializar el sistema visual mediante reglas de presentación consistentes, reutilizables y adaptables a distintos dispositivos.

---

### 9 · JavaScript

**Objetivo / Propósito:** Incorporar comportamiento, estados e interacciones significativas que enriquezcan la experiencia del portafolio sin perder claridad ni simplicidad.

---

### 10 · Publicación

**Objetivo / Propósito:** Publicar el portafolio y comprender el proceso necesario para desplegarlo, optimizarlo, mantenerlo y hacerlo evolucionar con el tiempo.


## Producto final

Al finalizar el programa habrás diseñado, desarrollado y publicado tu propio portafolio web.

El resultado será un sistema funcional construido a partir de tu contenido, tu identidad y tus decisiones. Más importante aún, comprenderás el proceso necesario para:

- organizar información antes de diseñar;
- representar jerarquías y relaciones;
- construir y aplicar un sistema visual;
- estructurar documentos con HTML;
- presentar interfaces con CSS;
- incorporar comportamiento con JavaScript;
- utilizar inteligencia artificial sin delegar el criterio;
- publicar, mantener y evolucionar un proyecto web.
