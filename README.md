# Portfolio WebCraft

_Construye tu propio portafolio mientras aprendes cómo funciona la web._

Aprende a organizar tu contenido, estructurar información y construir un sistema visual para dar vida a tu portafolio y publicarlo en línea.

**No necesitas saber programar.** Aprenderás los fundamentos del diseño y desarrollo web para escribir código asistido por IA.

*Tú defines la dirección creativa; la IA te ayuda a construirla.*

---

# Objetivo

Diseñarás, desarrollarás y publicarás un portafolio web profesional mediante una metodología que integra organización de información, sistemas visuales, desarrollo web e inteligencia artificial como herramienta de apoyo. Al finalizar el programa contarás con las bases necesarias para mantener y evolucionar tu sitio de forma autónoma.

---

## 1 · Identidad

Definirás el propósito de tu portafolio, tu identidad profesional y el contenido que dará origen a tu proyecto. Antes de diseñar o escribir una sola línea de código, tendrás claridad sobre qué quieres comunicar y cómo quieres presentarte.

---

## 2 · Contenido

Organizarás tu trabajo en un sistema de información claro, estructurando proyectos, categorías y jerarquías para transformar tu contenido en la base de un sitio web.

---

## 3 · Sistema Visual

Construirás un sistema visual que dará consistencia a todo tu portafolio. Definirás las reglas de tipografía, color, composición y componentes antes de comenzar el desarrollo.

---

## 4 · Entorno de Desarrollo

Prepararás un entorno de trabajo profesional para construir y mantener tu proyecto. Configurarás tu editor, conocerás las herramientas del flujo de desarrollo y aprenderás a utilizar la IA como asistente durante todo el proceso.

---

## 5 · Estructura (HTML)

Traducirás la arquitectura de información a una estructura web utilizando HTML semántico. Construirás las vistas principales de tu portafolio siguiendo buenas prácticas de organización y accesibilidad.

---

## 6 · Presentación (CSS)

Darás identidad visual a tu sitio utilizando CSS. Construirás una interfaz consistente, responsive y preparada para adaptarse a diferentes dispositivos.

---

## 7 · Experiencia (JavaScript)

Incorporarás comportamiento e interacciones que mejoren la navegación y la experiencia de uso de tu portafolio, entendiendo cuándo y por qué utilizarlas.

---

## 8 · Publicación

Publicarás tu portafolio en internet utilizando herramientas profesionales de control de versiones y despliegue. Además, comprenderás cómo mantener, actualizar y continuar evolucionando tu proyecto una vez publicado.

---

# Producto Final

Al finalizar el programa habrás diseñado, desarrollado y publicado tu propio portafolio web. Más importante aún, comprenderás el proceso completo para mantenerlo, mejorarlo y hacerlo crecer conforme evolucione tu práctica profesional.
